# 《中国艺术设计史》课件生成工具

用 Python 程序化生成《中国艺术设计史》（夏燕靖 · 第 3 版）教学课件：纹样配图全部由 PIL 代码绘制（抽象几何母题，非文物实拍），课件本体由 python-pptx 生成，主题采用「朱砂 · 黛青 · 赭金 · 宣纸」中式配色。

> 项目定位：**学习教育（Education / Learning）**。成品课件用于课堂讲授与自学梳理，工具链可复用于生成其他教学课件。

## 目录结构

```
.
├── build_deck.py              # 核心生成脚本（绘制纹样 + 生成 PPTX）
├── expanded-candidate.pptx    # 源候选课件（原始底稿）
├── assets/                    # 12 张程序化纹样素材（旋涡/水波/回字纹等母题）
├── output/                    # 成品课件
│   ├── 中国艺术设计史_优化课件_*.pptx
│   └── 中国艺术设计史_深化课件_*.pptx
├── .codex-build/              # 构建工作区
│   ├── course_content.mjs     # 课件内容（结构化讲义数据）
│   ├── *.mjs / *.ps1          # 构建与渲染脚本
│   ├── research-assets/       # 检索/抓取的研究参考素材（R01–R35）
│   └── *-renders/             # 渲染中间图与快照
├── .codex-finalizer/          # 收尾工作区（候选课件与校验）
├── LICENSE                    # MIT（仅适用于代码与工具链）
└── README.md
```

## 快速开始

依赖：Python 3.8+，`python-pptx` 与 `Pillow`。

```bash
pip install python-pptx pillow
python build_deck.py
```

生成结果输出到 `output/` 目录。

## 纹样与配色

- 配色：宣纸米白 / 朱砂红 / 黛青 / 赭金 / 墨色。
- 纹样：旋涡纹、水波纹、回字纹·方胜、菱形纹、莲瓣纹、团花纹、云纹、冰裂纹等抽象母题，均由代码程序化绘制，可无缝替换、缩放到任意分辨率。
